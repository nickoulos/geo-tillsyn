# origo-plugin

Handläggargränssnittet som plugin till [Origo](https://github.com/origo-map/origo): sidopanel med fastighetens tidslinje (ortofoto-årgångar + juridiska händelser + preskriptionsfönster), dossier med klickbara källor, regelgraf-vy och klarspråksversion.

*Hello-world i Sprint 1 (Spike B), dossier-vy Sprint 2, tidslinje Sprint 3.*
