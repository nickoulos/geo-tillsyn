# regelgraf

Juridiska beslutsträd per ärendeslag som explicita, granskningsbara grafer (YAML): noder = frågor med lagrum, kanter = svar, per nod anges vilka bevis (MCP-verktyg) som krävs. Språkmodellen fyller noder med citerade bevis — den improviserar inte juridik. Detta är svaret på "ingen svart låda".

Prototypfasen: grafer för Fall 1 (olovligt byggande), Fall 3 (lovavvikelse), Fall 7 (strandskydd).

*Fall 1+7 i Sprint 3, Fall 3 i Sprint 4, live-visualisering i Sprint 5.*
