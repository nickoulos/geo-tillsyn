# mcp-delta

Förändringsanalys mellan ortofoto-årgångar: koregistrering, differens, filtrering → kandidatpolygoner via zero-shot-segmentering (SAM2). Jämförelse mot byggnadsregister och lov-geometri. **Mätningar kommer alltid från GIS-geometri, aldrig från språkmodeller.**

*Byggs i Sprint 4; radar-batch i Sprint 5.*
