# mcp-regelverk

Tidsmedveten regeltolkning: `regelverk_vid(punkt, datum)` returnerar det juridiska sammanhang som gällde vid en given tidpunkt på en given plats — tillämplig PBL-version, detaljplan, strandskyddsstatus (inkl. utvidgat/upphävt), lovbefriade åtgärder (attefall fr.o.m. 2014), preskriptionsläge.

*Skelett i Sprint 1 (Spike D), utbyggnad Sprint 3.*
